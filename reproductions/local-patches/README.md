# Архив локальных patches

Эти patches сохранены для provenance, но не применяются
автоматически. Рабочее дерево сохраняет upstream-файлы без
изменений.

`reactor-source-revision-0bd2405.patch` фиксирует прежнюю локальную
привязку Reactor к старому commit. Для нового upstream она
не нужна и не должна применяться без отдельного решения.
